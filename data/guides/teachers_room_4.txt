TEACHER ROOM 4 - the senior faculty office

Welcome to the corner office. Papers everywhere, three dead plants, and
a computer that looks like it has classified opinions about the
curriculum. Don't touch the papers. Some of them are graded.

Your real target is the computer. It runs NixOS, which is a flavour of
Linux, which means everything lives in a "filesystem" and you poke
around it with typed commands - a text adventure inside the text
adventure. We're going deep. Hold on to something.

STEP ONE: TURN IT ON

  inspect computer

It'll whir, print a boot sequence that briefly worries you, flash the
logo, and dump you at a prompt that reads teacher@teacher-pc. You're
in. Type `help` any time to see the full command list.

THE COMPUTER COMMANDS
  ls              list what's in the folder you're standing in.
  ls -a           same, but also shows HIDDEN dot-files.
  cd <folder>     step into a folder (cd Documents).
  cd ..           step back up one folder.
  pwd             "where am I?" - prints the path.
  cat <file>      print a file's contents (cat README.txt).
  find            hunt through every folder for files.
  tree            draw the whole folder tree so you can see the shape.
  exit            leave the machine when you're done.

THE ACTUAL MYSTERY
The teacher hid "the schematic" somewhere on this machine. The note on
the desk - the one that says "its super secret", grammar left exactly
as found - points you here. There's also a README on the computer that
basically confesses: not every file shows up in a plain ls.

That's the whole trick. Linux hides things by starting their name with
a full stop (a "dot"), and plain `ls` politely pretends dot-files don't
exist. So the secret sits in a hidden folder, one flag away:

  ls
  cat README.txt
  ls -a
  cd .secret
  ls
  cat super_secret_file.txt

Read that file and the Secret Key copies itself into your inventory.
No, it's not a trap. And no, "its super secret" is still not a word.

WHEN YOU'RE DONE
`exit` the terminal. The clock pauses while you're inside, so you don't
get billed for your spelunking - very generous of it.

Now go poke around. The computer won't bite. Probably.
