#     ls             list what's in the folder you're currently standing in. 📂

#     cd <folder>    step into a folder (e.g., cd Documents).
#     cd ..          step back up one folder. 🔙
#     pwd            "where am I?" — prints your current folder path.
#     cat <file>     print a file's contents (e.g., cat README.txt). 📄
#     find           hunt through every single folder for files.
